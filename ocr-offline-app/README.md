# ТекстСкан — текст с любого изображения без интернета

ТекстСкан распознаёт текст на фото, скриншотах и сканах. Всё работает прямо на устройстве, интернет не нужен, изображения никуда не отправляются.

## Возможности

- **Распознавание без интернета.** Движок Tesseract (WebAssembly) и языковые модели для русского и английского лежат в папке `assets/`.
- **Любые изображения:** JPG, PNG, WEBP, BMP, GIF, HEIC (в Safari). Можно добавить несколько картинок сразу, перетащить их в окно или вставить из буфера (`Ctrl+V`).
- **Улучшение картинки.** Маленькие изображения увеличиваются, шум удаляется, контраст выравнивается. Светлый текст на тёмном фоне инвертируется. Изображение можно повернуть.
- **Неразборчивые слова дописываются автоматически, и видно, что было изменено:**
  - 🟩 **Исправлено** — слово было распознано с ошибкой и уверенно исправлено (`прнвет → привет`, `документьі → документы`, `pабота → работа` с латинской «p»);
  - 🟨 **Предположение** — слово читалось плохо, подставлен самый вероятный вариант;
  - 🟥 **Не разобрано** — уверенного варианта нет, слово стоит проверить;
  - ⌫ **Убран мусор** — точки и пятна, которые движок принял за буквы.

  Нажмите на подсвеченное слово, и откроется карточка. В ней показан кусок изображения с этим словом, то, что прочитал движок, его уверенность и другие варианты. Там же можно вписать своё слово, принять исправление («✓ Верно») или вернуть исходный вариант («↺ Как было»). На изображении слева такие слова обведены рамками.
- **Склейка переносов** (`распозна-` / `вание` → `распознавание`) и слов, разорванных пробелом.
- **Текст можно править** прямо в окне результата.
- **Копирование** одной кнопкой.
- **Скачивание в 8 форматах:** DOCX (Word), PDF, TXT, RTF, ODT (LibreOffice), HTML, Markdown, JSON. В DOCX, PDF, RTF, ODT и HTML исправленные слова можно выделить цветом. В DOCX к каждому такому слову добавляется примечание с исходным вариантом. JSON содержит все слова с уверенностью, координатами и списком исправлений.

## Как запустить

### Компьютер (Windows, macOS, Linux)

1. Скачайте папку `ocr-offline-app` целиком.
2. Откройте файл **`index.html`** двойным щелчком.

Проверено в Google Chrome. В других современных браузерах (Edge, Яндекс Браузер, Opera, Firefox, Safari) приложение тоже должно работать. Устанавливать ничего не нужно, ни сервер, ни интернет не требуются. Папку можно переписать на флешку и передать другому человеку.

### Телефон и планшет

На телефоне удобнее открыть приложение как сайт:

1. Разместите папку на любом хостинге статических сайтов, например GitHub Pages, Netlify или своём сервере.
2. Откройте адрес в браузере телефона и выберите «Добавить на главный экран» / «Установить приложение».
3. После первого открытия приложение сохраняется в памяти телефона и дальше работает без интернета. Кнопка «Сфотографировать» сразу открывает камеру.

## Как работает «логическое» дописывание слов

1. Tesseract возвращает каждое слово вместе с уверенностью распознавания.
2. Латинские буквы и цифры, похожие на русские (`a/а`, `p/р`, `0/о`, `3/з` …), внутри русских слов заменяются, и наоборот.
3. Слово, которого нет в словаре (≈218 тыс. русских и 88 тыс. английских словоформ с частотами), ищется среди похожих словарных слов. Похожесть считается с учётом типичных ошибок распознавания: `и↔н`, `ш↔щ`, `е↔с`, `rn↔m`, `ьі↔ы` и т. д. Чем чаще слово встречается в языке и чем меньше нужно исправить, тем выше вариант в списке.
4. Хорошо распознанные слова и редкие, но правильные формы («дописаны», «прочитанными») не трогаются. Имена собственные и аббревиатуры (ООО, ИНН) тоже.
5. Если результат распознавания в целом слабый, приложение само пробует другой способ разметки страницы и оставляет лучший вариант.

## Настройки

- **Язык текста:** русский + английский, только русский, только английский.
- **Тип изображения:** авто (документ, скриншот), один блок текста, разбросанный текст (вывески, фото), одна строка.
- Включение и выключение улучшения изображения, дописывания слов, склейки переносов, удаления мусора и объединения строк в абзацы.

## Структура

```
index.html               интерфейс
manifest.webmanifest, sw.js   установка как приложение и офлайн-кэш (при размещении на сайте)
assets/app.js            логика интерфейса
assets/ocr.js            подготовка изображения и запуск Tesseract без сети
assets/corrector.js      исправление и дописывание слов
assets/export.js         TXT, DOCX, PDF, RTF, ODT, HTML, MD, JSON
assets/vendor/           tesseract.js, ядро WebAssembly, jsPDF, шрифт для PDF
assets/lang/             языковые модели (rus, eng)
assets/dict/             частотные словари
tools/                   скрипты пересборки ресурсов
```

## Пересборка ресурсов (для разработчиков)

Готовые ресурсы уже лежат в `assets/`. Пересобирать их нужно только для обновления библиотек:

```bash
npm install
npm run build                          # tesseract.js, ядро, языковые модели, jsPDF
python -m venv .venv && .venv/bin/pip install wordfreq fonttools
.venv/bin/python tools/make_dict.py    # словари
.venv/bin/python tools/make_font.py    # шрифт с кириллицей для PDF
```

Сторонние компоненты и их лицензии перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
