# Тумблер — интернет-магазин бытовой техники

Учебный интернет-магазин на чистых HTML, CSS и JavaScript без сборки и без сервера.
Товары, бренды и цены вымышлены.

## Как запустить

Откройте `index.html` в браузере. Лучше запускать через локальный сервер, чтобы корзина и вход
работали одинаково во всех браузерах (Firefox хранит данные отдельно для каждого файла, открытого с диска):

```bash
cd appliance-store
npx serve .          # или: python3 -m http.server 8000
```

В VS Code подойдёт расширение Live Server.

**Демо-аккаунт** с историей заказов: `demo@tumbler.example` / `demo1234`
(на странице входа есть кнопка «Подставить»).

## Страницы

| № | Страница | Файл | Что есть на странице |
|---|----------|------|----------------------|
| 1 | Главная | `index.html` | строка поиска с подсказками; навигация (логотип, каталог, контакты, ЛК, корзина); баннер с прокруткой (автоматическая смена, стрелки, точки, свайп); форма подписки на рекламную рассылку; простой каталог: категории и популярные товары; подвал |
| 2 | Регистрация | `register.html` | навигация; форма регистрации с проверкой полей, маской телефона и индикатором надёжности пароля; переход на страницу авторизации; подвал |
| 3 | Авторизация | `login.html` | навигация; форма входа с показом пароля; переход на страницу регистрации; подвал |
| 4 | Личный кабинет | `account.html` | фото (загрузка и удаление); ФИО, телефон, почта с сохранением; смена пароля; покупки и заказы со статусами и кнопкой «Повторить заказ» |
| 5 | Корзина | `cart.html` | список товаров с фото и ценами; изменение количества; удаление с отменой; сумма корзины со скидкой и доставкой; оформление заказа |
| 6 | Каталог | `catalog.html` | список товаров; фильтры по категории, цене, бренду, классу энергопотребления, наличию и скидке; кнопки сортировки |
| 7 | Избранное | `favorites.html` | список избранных товаров; «Добавить всё в корзину»; очистка |

Ссылка «Контакты» в шапке прокручивает страницу к блоку контактов в подвале.

## Структура

```
appliance-store/
├── index.html, catalog.html, cart.html, favorites.html,
│   login.html, register.html, account.html
├── css/style.css   — стили, светлая и тёмная тема, адаптив под телефон
└── js/
    ├── data.js     — категории и товары
    ├── art.js      — SVG-иллюстрации техники (фото товаров)
    └── app.js      — шапка, подвал, корзина, избранное, вход, кабинет, каталог
```

Шапка и подвал общие для всех страниц: их строит `app.js`, поэтому правка в одном месте
меняет их на всём сайте.

## Где хранятся данные

Корзина, избранное, пользователи, заказы и подписчики лежат в `localStorage` браузера под ключами
`tumbler.*`. Чтобы начать с чистого листа, очистите данные сайта в браузере.

Пароли хэшируются простой функцией прямо в браузере. Это нормально для учебного проекта,
но в настоящем магазине регистрацию, вход и заказы обрабатывает сервер.

## Как добавить товар

Добавьте объект в массив `PRODUCTS` в `js/data.js`:

```js
{ id: 'kelvio-kr500', name: 'Kelvio KR-500', brand: 'Kelvio', cat: 'fridge', kind: 'Холодильник',
  art: 'fridge', color: 'white', price: 69990, old: 74990, rating: 4.6, reviews: 12, pop: 50,
  energy: 'C', specs: ['500 л', 'No Frost', '200 см'] }
```

- `cat` — id категории из `CATEGORIES`;
- `art` — рисунок: `fridge`, `fridge2`, `washer`, `dishwasher`, `oven`, `hob`, `microwave`, `vacuum`,
  `robot`, `iron`, `ac`, `kettle`, `coffee`, `blender`, `multicooker`;
- `color` — `white`, `silver`, `black`, `red` или `beige`;
- `old` — старая цена (необязательно), `energy` — класс A–G (необязательно),
  `stock: false` — нет в наличии, `isNew: true` — метка «Новинка».
